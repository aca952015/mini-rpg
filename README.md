# mini-rpg

抖音竖屏射箭成长小游戏，目前处于开发者工具空白模板阶段。

玩法参考 Zad Archery 的增量成长循环，以及《英雄没有闪》的竖屏侧视战斗与刷宝呈现。具体玩法和引擎模块尚未实现。

## 当前工程

- `game.js`：小游戏入口，保留开发者工具生成的 Canvas 2D 示例。
- `game.json`：小游戏配置，当前为竖屏。
- `project.config.json`：抖音开发者工具工程配置。
- `icon.png`：模板示例图片。

## 本地运行

1. 使用抖音开发者工具打开本目录。
2. 编译并预览，当前显示“抖音小游戏空白模板”。
3. 使用开发者工具的真机调试检查手机端效果。

当前工程不需要安装 npm 依赖，也没有额外构建步骤。
